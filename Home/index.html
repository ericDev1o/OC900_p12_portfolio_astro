Food Saver, votre application de lutte contre le gaspillage alimentaire

Découvrez ce projet▼

Contexte

Réalisation d’un Proof Of Concept de produit anti-gaspillage alimentaire. Le site web en français ou anglais liste vos aliments périssables à brève échéance avec des alertes. Le défi principal était de concevoir et développer une application web fullstack, testée et déployée, capable de gérer les données et fournir des notifications pertinentes pour réduire le gaspillage alimentaire.

Objectifs

Créer un site simple à utiliser selon la stack spécifiée en simplifiant maintenance et évolution par la documentation et les tests.

Stack technique

  • Front-end : React 19, TypeScript 7, Vite 8, TailwindCSS 4
  • Back-end : ASP.NET 10 (Minimal API), C# 14, Entity Framework Core 10
  • Base de données : SQLite (développement) et SQL Server (production)
  • Tests & Qualité : Cypress (tests end-to-end et accessibilité via axe-core), xUnit (tests unitaires API), OpenAPI 3
  • DevOps : Déploiement conteneurisé sur Render.com, optimisation de l’image Docker pour l’éco-conception

Compétences développées

  • Architecture Fullstack : Conception d’une API RESTful moderne avec ASP.NET 10 et intégration fluide avec un front-end React 19
  • Qualité & Accessibilité : Mise en place de tests E2E automatisés avec Cypress, ciblant spécifiquement les critères d’accessibilité (a11y) et la couverture fonctionnelle
  • Documentation Technique : Rédaction d’Architectural Decision Records (ADR) pour tracer les choix techniques et faciliter la collaboration future
  • Éco-conception : Optimisation de l’empreinte environnementale via du CSS natif au lieu de TailwindCSS et un conteneur Docker léger

Résultats et impact

Livraison d’un produit fonctionnel respectant les standards par itérations incrementales successives en moins de 4 semaines avec un premier Minimum Viable Product au bout de la première semaine

Perspectives d’amélioration

  • Échelle : Migration vers une architecture plus robuste pour gérer un volume élevé d’utilisateurs (base de données SQL Server complète, mise en cache)
  • Fonctionnalités : Ajout de la synchronisation cloud, notifications push mobiles et intégration avec des listes de courses
  • Performance : Optimisation supplémentaire du bundle React et mise en place d’un service de recommandation de recettes basé sur les aliments disponibles

Le défi principal était d’intégrer une API WordPress 2 (REST API) pour récupérer les données en temps réel et de les afficher de manière fluide et accessible, tout en optimisant les performances de chargement des tuiles cartographiques.

Objectifs

Créer une interface de carte intuitive et performante, facilitant l’engagement citoyen par la visualisation de données. Assurer une maintenance simplifiée grâce à l’automatisation des tests et à l’assistance IA pour la génération de code.

  • Front-end : JavaScript (ES6+), Leaflet Map 3.4.7, WordPress 7.1.4 (REST API 2)
  • Outils IA : GitHub Copilot (VSCode) pour l’assistance à la génération de code
  • Tests & Qualité : Tests E2E d’accessibilité et de fonctionnalité en Playwright & axe-core

Compétences développées

  • Intégration API : Consommation et traitement de données JSON via l’API WordPress REST pour une mise à jour dynamique de la carte
  • Géolocalisation : Implémentation de cartes interactives performantes avec gestion des événements de zoom et de clic
  • Assistance IA : Utilisation surveillée de GitHub Copilot pour accélérer le développement, refactoriser le code et générer des tests

Livraison d’une carte interactive fonctionnelle et adaptative aux terminaux, permettant une visualisation claire des données du mouvement. Réduction du temps de développement grâce à l’assistance IA.

Perspectives d’amélioration

  • Visualisation : Adaptation de la carte et des encarts informatifs au défilement d’écran
